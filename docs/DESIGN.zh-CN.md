# 架构与证据边界

## 集成

动态库使用 CPA 的稳定 JSON-over-C ABI，ABI 版本为 1，schema 版本为 6。唯一声明的能力是 `management_api`；没有注册请求拦截、路由、凭据修改或自动生成能力。

公开资源仅包含静态界面文件。账号发现、批次创建、进度、生成内容、导出、历史删除、基线修改及清理都通过需要鉴权的管理路由处理。Manager 前端使用已有认证连接，转发同源 model-quality iframe 的请求。消息必须来自当前活动 iframe，并符合其来源约束。转发范围仅限本插件的 API 前缀，卸载页面时会中止请求；凭据始终保留在父页面，不会发送到 iframe。因此，在 Manager 内使用插件不需要再次登录；独立访问仍提供仅在内存中使用的管理密钥表单。

内部模型调用回调携带明确的凭据 ID、提供商和模型。禁用凭据会被拒绝，重试时仍重新查找同一凭据。预期答案和解释不会进入生成请求。短时管理请求的宿主回调上下文 ID 不会附加到异步任务上。

## 生命周期

同一时间只运行一个批次。工作池的并发数和请求数量都有上限。每个任务从排队进入运行状态，并最终到达且仅到达一个终态。取消会停止接收排队任务，并关闭已建立的宿主模型流。如果模型回调仍在建立初始流，需要等建立完成后才能关闭；在工作线程实际结束前，界面会保持“正在取消”。

Quiesce 会关闭活动批次并等待工作线程。重启后未完成的批次被标记为中断，已有回复会保留。重试创建独立批次并关联原批次 ID，同时保留原提示词、预期字段和评分器版本。

## 存储

私有 JSON 文件先写入临时文件，执行 fsync 后再替换。文件权限为 `600`，目录权限为 `700`。运行时凭据和管理员密钥不属于存储结构。保留策略按时间、批次数和磁盘预算清理，同时保留活动批次及选定基线。基线原子写入 `settings.json`。

## 评分

解析器要求显式且成功的流完成状态。对于 Responses 请求，仅有 `[DONE]` 或连接 EOF 不足以视为完成。错误、未完成、取消、缺少完成标记、空输出及超出限制都不会得到零分评分。

严格 JSON 解析会递归拒绝重复键、过深嵌套和尾随内容。数值比较保持精度，并对数字长度和指数设置限制，约束评分开销。字段按结构比较，区分不同类型。格式检查与答案检查相互独立。选择题只接受唯一、位于末行的 `FINAL: X`。

仅当所有请求的客观题都成功评分时，界面才展示完整客观题平均分。绘图、自由文本、自定义题及只检查格式的 IFEval 题不计入该平均分。基线差值要求账号、请求模型、推理档位、精确题目哈希、评分器版本和重复轮次都一致。

## 预览

模型返回的 HTML 不会插入应用 DOM。它先作为非活动文档解析，再放入沙箱 iframe；iframe 使用不透明源，脚本仅允许在该 iframe 内执行。额外的限制性 CSP 阻止网络连接、嵌套框架、表单、外部资源和对象嵌入。该框架不能读取父页面 Cookie、密钥或应用存储。下载的 HTML 也会加入相同的限制策略。

## API

以下路径均相对于 `/v0/management/plugins/model-quality/`：

| 方法 | 路径 | 操作 |
| --- | --- | --- |
| GET | bootstrap | 账号和模型元数据、题库、当前批次及基线 |
| POST | batches | 启动用户明确请求的批次 |
| GET | batches | 历史批次摘要 |
| GET | batch?id= | 进度及元数据，不含完整回复 |
| GET | artifact?id=&item= | 单条原始回复和可选 HTML |
| POST | cancel | 按 ID 取消活动批次 |
| POST | retry | 为指定任务或未完成任务创建新批次 |
| GET | export?id= | 完整批次 JSON |
| DELETE | batch | 删除非活动且非基线的历史批次 |
| POST | baseline | 选择已完成的参考批次或清除基线 |
| POST | cleanup | 应用配置中的保留策略 |
